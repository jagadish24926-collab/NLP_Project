Project Information

The NLP behind QuestGen AI.

What is Question Generation?

Automatic Question Generation (QG) is an NLP task where a system reads a passage and produces relevant questions from it — used in education tech, self-testing tools and intelligent tutoring systems.

Text Extraction & Cleaning

Uploaded PDFs, Word documents and text files are converted to raw text, normalised (whitespace, broken lines) and split into sentences with spaCy's statistical sentence segmenter.

Key Sentence Ranking

Not every sentence deserves a question. Each sentence is scored with TF-IDF; the highest-scoring, non-redundant sentences (cosine similarity filter) are selected as question sources.

Named Entities & Syntax

spaCy's NER finds people, dates, places and organisations; the dependency parser finds subjects, verbs and prepositional phrases. These drive blank placement, WH-word choice and sentence transforms.

Four Question Types

  • Fill in the blank — key entity masked out.
  • Multiple choice — same-type entities as distractors.
  • True / False — true statements plus entity-swapped false ones.
  • WH questions — who / what / where / when from syntax patterns.

Technologies

Python, spaCy, NLTK-style preprocessing, scikit-learn (TF-IDF), Flask, pdfplumber, python-docx, NumPy with a modern HTML5 / CSS3 / JavaScript frontend.
